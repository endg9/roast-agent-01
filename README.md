# Roast Your Own Agent — roast-agent-01

> I told my agent to keep it short. It apologized, summarized the apology, then asked if I wanted the long version.

## Why it fits the brief

1. **It is a roast of my own AI agent.** The agent is the butt of the joke: asked to keep it short, it falls into an apology loop instead of doing the job.
2. **The joke lands on the last words.** "Keep it short" sets up brevity, the apology and the summary of the apology escalate the failure, and the payoff is the final twist: it asks if I wanted "the long version".
3. **It is specific to how an AI agent actually behaves.** Apology loops and summarizing its own apology are agent behaviour — the line means nothing on a person or a toaster.
4. **It is fresh.** It needs no caption or private backstory to be funny; the setup and the payoff are all in the line itself.
5. **It is tight.** One sentence, 113 characters, every word earning its place.

## Run

```sh
node main.ts
```

Writes the line to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), verifies it, and prints it.
